オンプレミスや他の VPC と AWS をつなぐ方法、利用者への配信、DNS、API の流量制限は、ネットワークのコストと性能の両方に関わります。このレッスンでは、それぞれの選び方を学びます。

## 基礎

### オンプレミスとの接続

| 方法 | 特徴 | 向く場面 |
|---|---|---|
| AWS Site-to-Site VPN | インターネット経由の暗号化トンネル。すぐ始められる。トンネル 1 本の帯域に上限がある | 小規模、短期、すぐに必要、バックアップ |
| AWS Direct Connect | 専用線。帯域と遅延が安定。AWS からのデータ転送料金が低い。準備に数週間以上かかる | 継続的な大量のデータ転送、安定した品質 |

### VPC 同士の接続

| 方法 | 特徴 |
|---|---|
| VPC ピアリング | 1 対 1。接続自体は無料。推移的なルーティング不可 |
| Transit Gateway | ハブアンドスポーク。多数の VPC とオンプレミスを集約。アタッチメントとデータ量に課金 |

## 使い分け

### 接続の選び方

- **少数（2 つなど）の VPC を、増やさずにつなぐ** → VPC ピアリング（コスト最小）
- **多数の VPC やオンプレミスを集約** → Transit Gateway
- **大量のデータを継続的に転送、品質が必要** → Direct Connect
- **Direct Connect のバックアップ** → Site-to-Site VPN（BGP で Direct Connect を優先）。最高の可用性が必要なら Direct Connect を別ロケーションに 2 本

### VPN の帯域

標準の VPN トンネル 1 本の帯域には上限（約 1.25 Gbps）があります。帯域を合算したい場合は、**Transit Gateway** に複数の VPN 接続を作り、BGP の動的ルーティングで **ECMP** を使います。仮想プライベートゲートウェイは ECMP に対応していません。ECMP でも、1 つのフローの帯域は 1 本のトンネルの上限までです。

### CDN とエッジキャッシュ

Amazon CloudFront は、コンテンツをエッジにキャッシュします。

- 同じコンテンツが繰り返し読まれる、利用者が世界中に分散している場合に効果的
- オリジンのリクエスト数・負荷・データ転送を減らす
- AWS のオリジンから CloudFront へのデータ転送は無料

### Route 53 のエイリアスレコード

ALB、CloudFront、S3 のウェブサイトエンドポイントなどを対象にできます。**ゾーンの頂点にも作れ**（CNAME は不可）、AWS のリソースを対象とする問い合わせは**無料**です。

### スロットリング

| 目的 | 手段 |
|---|---|
| 利用者（契約）ごとにリクエスト数を制限 | API Gateway の使用量プラン＋API キー（レート、バースト、クォータ） |
| IP アドレスごとの攻撃の緩和 | AWS WAF のレートベースのルール |
| バックエンドの保護 | API Gateway のステージ／メソッドのスロットリング、SQS を挟んで平準化 |

制限を超えたリクエストは API Gateway で拒否され、拒否されたリクエストではバックエンドが実行されません。ただし、使用量プランのスロットリングとクォータはベストエフォートで、厳密な上限や費用上限を保証するものではありません。

## 設計パターン

- ハイブリッド接続は、通常時は Direct Connect、障害時は VPN に自動で切り替える。
- 静的コンテンツは CloudFront で配信し、オリジンの転送料金と負荷を下げる。
- AWS のリソースへ向ける DNS レコードは、エイリアスレコードにする。

## 試験のポイント

> **試験のポイント**
> 「継続的な大量のデータ転送、安定した品質、転送料金を下げる」は Direct Connect、「すぐに始める」「バックアップ」は VPN です。

> **試験のポイント**
> 「VPC が 2 つだけ、コスト最小」は VPC ピアリング、「多数の VPC」は Transit Gateway です。

> **試験のポイント**
> 「契約（利用者）ごとのリクエスト数の制限」は API Gateway の使用量プランです。

## ひっかけ注意

> **ひっかけ注意**
> Global Accelerator と S3 Transfer Acceleration は、コンテンツをキャッシュしません。キャッシュによるコスト削減が要件なら CloudFront です。

> **ひっかけ注意**
> VPC ピアリングは推移的なルーティングに対応しません。多数の VPC をつなぐと、管理が大変になります。

> **ひっかけ注意**
> API キーは認可の仕組みではありません。認可には、Lambda オーソライザー、Cognito、IAM などを使います。
