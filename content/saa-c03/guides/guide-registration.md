AWS 認定ソリューションアーキテクト – アソシエイト（SAA-C03）の申し込みから、受験当日、結果の確認、認定の更新までの流れをまとめます。手続きの決まりは変わることがあります。予約の前に、末尾の出典にある公式ページで最新の内容を確かめてください（このガイドの確認日は 2026-11-04 です）。

## 1. 試験の概要

| 項目 | 内容 |
|---|---|
| 試験コード | SAA-C03 |
| 問題数・時間 | 65 問（採点対象 50 問）・130 分 |
| 合格点 | 720 点（スケールスコア 100〜1,000） |
| 受験料 | 150 USD。日本円で支払う国では 20,000 円（別途、税がかかる場合あり）。1 回の受験に対する料金 |
| 受験方法 | Pearson VUE のテストセンター、またはオンライン監督試験（OnVUE） |
| 言語 | 日本語、英語など |
| 認定の有効期間 | 3 年 |

## 2. 申し込みの流れ

1. **AWS 認定アカウントを作ります。** AWS 認定アカウントは、ふだん使う AWS アカウントとは別のものです。aws.training/Certification からサインインし、案内に従って AWS Builder ID を作成してサインインします。
2. **氏名を正しく登録します。** 当日に提示する本人確認書類の姓と名は、AWS 認定アカウントに登録した姓と名と完全に一致していなければなりません。ローマ字のつづりも含めて、書類と同じにします。
3. **試験を予約します。** AWS 認定アカウントで新しい試験の予約を選び、SAA-C03 と受験の言語を選びます。続いて Pearson VUE の画面で、テストセンターかオンライン受験か、日時を選びます。
4. **受験料を支払います。** 割引の受験バウチャーを持っていれば、ここで使います。
5. **確認メールを受け取ります。** 予約の内容と、当日の案内が届きます。

> **試験のポイント**
> 英語で受験する英語ネイティブでない人は、30 分の時間延長（ESL +30）を申請できます。申請は試験を申し込む前に 1 回だけ行えば、その後のすべての予約に適用されます。日本語で受験する場合は対象外です。

## 3. 予約の変更と取り消し

| 決まり | 内容 |
|---|---|
| 変更・取り消しの期限 | 予約時刻の 24 時間前まで（追加料金なし） |
| 24 時間を切ったあと | 変更も取り消しもできず、返金されない |
| 変更できる回数 | 1 つの予約につき 2 回まで。3 回目は、いったん取り消してから予約し直す |
| 無断欠席・遅刻 | 受験料は戻らない。予約時刻に 15 分以上遅れると試験を始められない |
| 例外 | 本人の病気や緊急事態で、書類で証明できる場合は、試験の配信事業者が対応することがある |

## 4. テストセンターとオンライン受験の違い

| 項目 | テストセンター | オンライン受験（OnVUE） |
|---|---|---|
| 場所 | Pearson VUE のテストセンター | 自宅や職場などの、ひとりになれる部屋 |
| パソコン | 会場のものを使う | 自分のパソコンを使う |
| 本人確認書類 | 2 点（プライマリ ID 2 つ、またはプライマリ ID 1 つとセカンダリ ID 1 つ） | 1 点（プライマリ ID 1 つ） |
| 到着・開始 | 予約時刻の 15〜30 分前に到着 | 予約時刻の 30 分前から試験を起動できる |
| 休憩 | 臨時の休憩は可能。ただし試験時間は止まらない | 一切できない（お手洗いも不可）。カメラの範囲から離れられない |
| 試験監督者 | 会場のスタッフ | Web カメラと画面共有で遠隔から監督。日本語の監督者は月〜土曜日の 9:00〜16:00（日本時間）。英語は 24 時間 |

### 本人確認書類

- **プライマリ ID**: 有効期限内の原本で、政府が発行したものです。コピーやデジタルの ID は使えません。公式ページの例は、パスポートと運転免許証です。
- **セカンダリ ID**: ローマ字の姓と名に加えて、署名か、顔が分かる最近の写真が入っている書類です。
- 期限切れや破損した書類、コピーや紙の書類、デジタルの書類は使えません。
- マイナンバーカードや在留カードなど、ほかの書類が使えるかどうかは、受験の前に Pearson VUE の本人確認書類の規定や予約の確認メールで確かめてください。
- 公式ページには、日本で受験する日本人向けの例外（写真付きの社員証または学生証と、日本の健康保険証の 2 点）も書かれています。ただし健康保険証は新規の発行が終わっているため、この組み合わせを使う場合は事前に Pearson VUE に確認してください。

### オンライン受験の準備

- **事前にシステムテストを実行します。** 当日に使うのと同じパソコン、同じネットワークで、Pearson VUE のシステムテストに合格しておきます。当日にシステムテストに合格しないと、試験を始められず、受験料も戻りません。
- **パソコン**: Windows 10 以降または macOS 14 以降（要件は変わることがあるので、Pearson VUE の要件ページで確認します）。Web カメラ、マイク、スピーカーが必要です。
- **画面は 1 台だけ**にします。外付けのモニターは外します。
- **ネットワーク**: 安定した回線を使います。VPN や会社のネットワーク、公共のネットワークは避けます。
- **部屋**: ひとりになれる静かな部屋で受験します。机の上を片づけ、試験中は誰も入らないようにします。
- **開始の手続き**: 予約時刻の 30 分前から起動できます。本人確認書類の撮影や部屋の確認があるので、早めに始めます。

## 5. 受験当日

- テストセンターには、予約時刻の 15〜30 分前に着くようにします。荷物は会場の指示に従って預けます。
- オンライン受験は、予約時刻の 30 分前から起動できます。試験中は席を立てないので、始める前にお手洗いを済ませておきます。
- 試験の進め方は「試験の進め方」のガイドを参照してください。日本語で受験していても、試験中に切り替えの機能を使って問題を英語で表示できます。

## 6. 結果の確認

- 最終的な結果は、試験の終了から 5 営業日以内に AWS 認定アカウントに掲載されます。セキュリティや技術上の理由で確認が必要な場合は、遅れることがあります。
- スコアレポートは、AWS 認定アカウントの試験履歴（Exam History）からダウンロードできます。
- スコアレポートには、ドメインごとの出来ぐあいの分類が載ることがあります。苦手なドメインを見つける参考にします。

## 7. 不合格だったとき

- 不合格の場合、**14 日（暦日）たてば再受験できます**。
- 受験できる回数に上限はありませんが、毎回、受験料を全額支払います。
- 合格した試験は、同じ試験を 2 年間受験できません。

## 8. 認定の有効期間と更新

認定の有効期間は 3 年です。有効期間内に、次のどれかで延長できます。試験に合格して更新すると、合格した日から 3 年間有効になります。

| 方法 | 内容 | 延長される期間 |
|---|---|---|
| 最新版の SAA に合格する | AWS 認定アカウントにある 50% 割引のバウチャーを使える | 3 年 |
| AWS Certified Solutions Architect - Professional（SAP）に合格する | 上位の認定に合格すると、アソシエイトの認定も更新される | 3 年 |
| AWS Skill Builder で認定を維持する | AWS Skill Builder の有料のサブスクリプションで受けられる（条件は公式ページで確認） | 1 年 |

> **ひっかけ注意**
> 更新や維持は、認定が有効なうちにしかできません。期限が切れると、もう一度最初から受験することになります。方法ごとに手続きできる時期などの条件があるので、期限が近づく前に公式ページで確かめ、どの方法で更新するかを決めておきます。

## 9. 受験前のチェックリスト

- AWS 認定アカウントの氏名と、本人確認書類の氏名が完全に一致している
- テストセンターなら本人確認書類が 2 点、オンライン受験なら 1 点そろっている（有効期限内の原本）
- オンライン受験なら、同じパソコンとネットワークでシステムテストに合格している
- 予約の変更・取り消しは 24 時間前までと分かっている
- 当日は、テストセンターなら 15〜30 分前に到着、オンラインなら 30 分前から起動する
